# S参数端口注释规则集

不同仿真工具在 Touchstone 文件抬头中记录的端口信息并不相同：有的注释描述矩阵列序，有的给出矩阵位置与物理端点的对应关系。本仓库整理了 ADS、Ansys 和 Cadence 三类导出样例的抬头编写与识别规则，并收录厂商规则不匹配时的数字端口识别规则。

## 收录内容

| 规则文档 | 主要内容 |
| --- | --- |
| [ADS 抬头规则](ads_spara_portrule.md) | 以四端口全矩阵样例说明网络声明、来源块和矩阵列标签的含义，区分矩阵索引与物理端口名称。 |
| [Ansys 抬头规则](ansys_spara_portrule.md) | 说明 HFSS 3D Layout 与 Circuit Design 终端导出中的端口编号、完整名称及可识别的器件、管脚和网名字段。 |
| [Cadence 抬头规则](cadence_spara_portrule.md) | 区分端口主表行序与工程 ID，说明差分通道与端口的绑定关系，以及与 Ansys 端口表互转时可能丢失的信息。 |
| [通用数字端口规则](generic_spara_portrule.md) | 适用于抬头不匹配上述三类规则的文件，说明 `.sXp` 后缀能提供的端口编号范围，不推断物理名称或差分绑定。 |

四份文档均涉及端口数的一致性核验：文件后缀、抬头声明或完整端口表、首个频点的实际矩阵元素数是三项独立依据。三项一致才称端口数已确认；缺项要说明，已知值冲突要报告，不能改用通用规则掩盖冲突。

## 适用范围

已有文件互转抬头时，只改首个 S 参数频点之前与转换有关的 `!` 注释。所有 `#` 选项行（如 `# Hz S RI R 50`）原样保留；从首个频点所在行到文件末尾逐字节不变。

Cadence 标准主表可混用有管脚和无管脚的端口记录，矩阵位置始终由主表行序决定。读取时优先按器件、管脚映射识别；无法确认时，有编号前缀的记录保留完整器件名，无前缀的记录保留完整自由名。

其他格式转入 Cadence 时，三字段齐全且可确认就优先写 `! [comp]_[pin]::[net]`；其次写 `! [name]::[net]`，未知网名留空。没有物理名称但矩阵位置已确认时，按一基位置写 `! Port1::`、`! Port2::` 等，不限于 ADS 来源。只有后缀时仅报告数字端口，不自动覆盖。

本仓库提供规则文档和合成抬头示例，不包含解析器或仿真程序。厂商规则描述的是特定导出样例，不代表各版本的完整格式规范；实际软件的导入兼容性未经验证。
